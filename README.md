# HC Dance & Design
En responsiv hemsida för dansföreningen HC Dance & Design.

## Om webbplatsen
En hemsida som består av tre olika THML filer som innehåller infromatuon, event och ett kontaktformulär. En anpassad sida som ska fungera som ett alternativ till den offentliga webbplatsen för HC D&D, lätt att naviger och tydlig kontrast mellan text och bakgrund.

### Index/Startsidan
* Om oss
* Vår sammarbetspartner - Alnö linecande

### Event
* Winter Dance 2027 med en kanpp med en länk till Alnö Linedance hemsida
* Öppen dans med en knapp med en länk till Facebook eventer

### Kontakt
* Information om tjänsterna som erbjuds
* Kontaktformuläret

## Tekniker
* HTML
* CSS
  - CSS Grid
  - Flex och flexbox
* JavaScript
